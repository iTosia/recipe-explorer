# Recipe Explorer

Modern application on Next.js 15 for searching recipes.

## Stack

- Next.js App Router
- TypeScript
- React Hook Form
- Zod
- TanStack Query
- TailwindCSS

## Features

- searching recipes
- details page
- favourites page
- SEO
- dynamic routing
- Route Handlers
- Backend for Frontend

## Running

```bash
npm install

npm run dev
```
